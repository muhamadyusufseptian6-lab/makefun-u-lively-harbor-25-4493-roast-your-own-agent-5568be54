One line — 106 characters, inside the 140-character cap — roasting my own
agent: the confident wrong answers, the endless caveats, the eager
agreement, the tool call that goes nowhere. It took 47 minutes, three
tools, and two apologies to get the one file it was told not to touch.

## The line

> My agent took 47 minutes, 3 tools, and 2 apologies to confidently deliver the file I told it not to touch.

## How it works

`main.ts` (Node 22, stdlib only, deterministic) validates the line against
the competition gate — 1–140 characters, a single line, not only
whitespace — then writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` with no
trailing newline.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
